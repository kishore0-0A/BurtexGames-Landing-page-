# Burtex Games CHENNAI — COMPLETE WEBSITE UI/UX DESIGN PROMPT

Design a complete, premium, modern, responsive website for **Burtex Games Chennai**, an indoor entertainment, sports, gaming, and events destination in Chennai.

This is a **client project for DomainX**. The objective is to replace the existing Burtex Games website with a significantly more modern, immersive, conversion-focused digital experience.

The website must feel like a **premium entertainment destination**, not a generic corporate website or simple bowling-alley website.

The primary goal is to help users:

**Discover → Explore → Choose an Experience → Check Pricing → Book → Pay → Receive Confirmation**

The secondary goals are:

- Promote Burtex Games as a complete entertainment destination
- Increase online bookings
- Promote birthday and corporate events
- Promote tournaments
- Showcase the venue visually
- Make pricing easy to understand
- Build trust through reviews
- Provide easy access to WhatsApp, phone, location, and directions
- Create a scalable visual system that can later connect to a booking backend and admin dashboard

**Headings: Space Grotesk / Sora / similar modern geometric font**

Typography hierarchy:

- Huge cinematic hero heading
